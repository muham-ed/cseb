# Changelog

All notable changes to the CSEB project will be documented in this file.

## [1.0.0] - 2026-10-17

### Added
- **Layer 1 (Generation)**: Parametric synthetic template-based COBOL generator with zero seed variance.
- **Layer 2 (Validation)**: Native GnuCOBOL 3.1 execution engine inside WSL Ubuntu with automated output matching.
- **Layer 3 (Enrichment)**: McCabe cyclomatic complexity calculation, domain classifier, and bilingual (EN/AR) descriptions.
- **Layer 4 (Storage)**: Relational SQLite schema, JSONL, Parquet, and standalone SQLite dataset exporter.
- **Layer 5 (Benchmark)**: Benchmark task builder, evaluation harness, and model leaderboard generator.
- **Layer 6 (Legal)**: Automated SPDX license scanner and legal provenance tracking.
- **Dashboard & API**: Interactive Streamlit dashboard and FastAPI documentation server.
- **Test Suite**: Comprehensive Pytest suite with 100% pass rate.
