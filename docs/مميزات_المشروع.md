# ⚡ مشروع CSEB — COBOL Synthetic Enterprise Benchmark

---

## 📌 1. عن ماذا يتحدث المشروع؟ (Overview)

مشروع **CSEB** هو إطار عمل ومعيار تقييم سحابي وموحد (**Benchmark & Dataset Generator**) مخصص للذكاء الاصطناعي ولغة **COBOL** المستعملة في البنوك والمؤسسات المالية والمطارات والقطاعات الحكومية حول العالم.

### ❓ المشكلة التي يحلها المشروع:
1. **ندرة البيانات المفتوحة**: أكثر من **80%** من المعاملات المالية حول العالم تعتمد على لغة COBOL، لكن الأكواد مملوكة للبنوك ومحفوفة بالسرية والمحاذير القانونية (NDAs & Privacy).
2. **صعوبة تدريب نماذج الذكاء الاصطناعي**: نماذج مثل GPT-4 و Claude و Copilot تعاني في فهم وتحديث أكواد COBOL القديمة لعدم وجود بيانات تدريبية موثوقة ومفحوصة تنفيذياً.
3. **غياب معايير التقييم (Benchmarking)**: عدم وجود مقياس موحد لمعرفة دقة أي نموذج ذكاء اصطناعي عند تحويل أو كتابة أكواد الكوبول.

### 💡 الحل الذي يقدمه CSEB:
توليد أكواد COBOL معقدة وشبيهة بأكواد المؤسسات المالية بشكل **تركيباتي نقي (100% Clean-Room Synthetic)** مع التحقق من صحة تشغيلها عبر مترجم **GnuCOBOL** وإثرائها بوصف عملي ثنائي اللغة (عربي/إنجليزي)، مع توفير بيئة قياس ودقة لنماذج الذكاء الاصطناعي وإتاحة تصديرها لكل المنصات (مثل HuggingFace و SQLite و Parquet).

## 🚀 2. مميزات المشروع ونقاط القوة (Key Features & Highlights)

### 🏗️ 1. معمارية منظمة من 6 طبقات متكاملة (6-Layer Architecture)
- **طبقة التوليد (Generation Layer)**: توليد أكواد موجهة تشمل المعاملات المالية المصرفية (`EXEC SQL / DB2` و `EXEC CICS` وملفات `VSAM` و `COPYBOOKS`).
- **طبقة التحقق (Validation Layer)**: ترجمة وتشغيل تلقائي عبر **GnuCOBOL 3.1** ومقارنة المخرجات الفعلية مع المخرجات المتوقعة بـ (100% Exact Matching).
- **طبقة الإثراء والشرح (Enrichment Layer)**: حساب التعقيد البرمجي (McCabe Complexity) وتوليد شرح عربي وإنجليزي لكل كود واستخراج الاعتماديات والتصنيف القطاعي (البنوك، المحاسبة، الأجور، التأمين، الموارد البشرية، المخازن).
- **طبقة التخزين والتصدير (Storage Layer)**: قاعدة بيانات موحدة SQLite مع إمكانية التصدير الفوري لصيغ `Parquet` و `JSONL` و **HuggingFace Datasets**.
- **طبقة التقييم والمقارنة (Benchmark & Leaderboard)**: أداة قياس تقارن أداء مختلف نماذج الذكاء الاصطناعي (مثل OpenAI vs Anthropic vs Ollama) وتنشئ قائمة متصدرين (Leaderboard) تلقائية.
- **طبقة الملكية والأمان القانوني (Legal Provenance Layer)**: تتبع مرمز بتوقيع مشفر (SHA256) وتأكيد خلو الأكواد تماماً من أي انتهاك لحقوق الملكية أو تسريب لأكواد الشركات.

---

### 🌟 2. المزايا التنافسية الفريدة (Unique Selling Points)
- 🌐 **دعم كامل للغة العربية (Bilingual Support)**: أول بنشمارك عالمي يوفر شرحاً وتوصيفاً باللغتين العربية والإنجليزية لبيانات COBOL.
- 🔒 **شرعية قانونية واستخدام تجاري حر 100%**: مرخص بترخيص **MIT** المفتوح دون قيود تجارية، مما يتيح للبنوك والشركات استخدامه وتدريب نماذجهم بأمان تام.
- 🧪 **تحقق تنفيذي حقيقي وليس مجرد فحص نظري**: يضمن أن الكود المولّد قابل للترجمة والعمل التشغيلي التام وليس مجرد نصوص جامدة.
- 📊 **لوحة تحكم تفاعلية (Streamlit Dashboard)**: واجهة مرئية استعراضية لمتابعة الإحصائيات، فحص الأكواد، وتتبع لوحة المتصدرين.
- ⚡ **واجهة برمجة تطبيقات متكاملة (FastAPI Backend)**: توفير REST APIs لإدماج البنشمارك مع أي أنظمة أخرى بسهولة.

## 🛠️ 4. المكونات التقنية للمشروع

- **اللغة الأساسية**: Python 3.13
- **المترجم المدمج**: GnuCOBOL 3.1 (عبر بيئة WSL Ubuntu)
- **قواعد البيانات**: SQLite / Pandas / Parquet / JSONL
- **واجهات المستخدم**: Streamlit
- **الـ APIs**: FastAPI / Uvicorn
- **بيئة الاختبارات**: Pytest (مع تغطية اختباريّة 100% للوظائف الحيوية)
